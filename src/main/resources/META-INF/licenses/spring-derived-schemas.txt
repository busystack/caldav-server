Spring-derived JDBC schemas (Apache License 2.0)

Source artifacts remain unchanged and include their Apache license:
org.springframework.security:spring-security-oauth2-authorization-server:7.1.2
org.springframework.security:spring-security-webauthn:7.1.2
org.springframework.session:spring-session-jdbc:4.1.1

V3__spring_oauth_authorization.sql adapts the upstream registered-client,
authorization and consent SQL schemas. BusyStack changed PostgreSQL blob/text
and timestamp/timestamptz types as instructed by the upstream schema, and adds
application-owned persistent refresh families and their constraints.

V4__persistent_passkeys.sql adapts the column contract consumed by the Spring
Security JdbcUserCredentialRepository. BusyStack adds stable-account ownership,
foreign keys, UV/counter constraints and application metadata.

V6__sessions_recovery_protection.sql includes the upstream Spring Session
org/springframework/session/jdbc/schema-postgresql.sql table/index structure,
then adds application-owned recovery, ceremony, throttling and security state.
The original SQL entry does not carry a per-file copyright header; the original
artifact's Apache license is retained. Published Spring Session 4.1.1 POM
metadata was confirmed erroneous by its maintainer in issue #3910.

These are notices identifying the adaptations without changing the checksums
of already-applied Flyway migrations V1–V9. The original schemas can be read
from the unmodified nested dependency artifacts and their published sources.
