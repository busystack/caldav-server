Set up BusyStack

Your server is running and needs its first administrator.

On the server, open the extracted deployment folder that contains compose.yaml and the scripts. Run:

bash scripts/initialize.sh

The code expires after 15 minutes. Run the command again to replace an expired code or a code locked after repeated unsuccessful attempts.
