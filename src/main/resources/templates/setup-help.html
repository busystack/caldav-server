Setup and recovery help

Set up a new server

From the extracted deployment directory on the server, run bash scripts/initialize.sh. Paste the code into the setup form within 15 minutes. Issuing a replacement invalidates the old code.

Open setup

Recover an existing account

Sign in with your password or organization account. If you lost your passkey, use a saved recovery code at the verification step. Contact the deployment operator for controlled offline recovery if you cannot use that option.

The extracted deployment includes docs/GETTING_STARTED.md and docs/operations.md.
