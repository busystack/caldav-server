OAuth clients

AdministrationVerify password and passkey

Register a calendar or task application that supports authorization code with S256 PKCE. Native applications use public client identification and have no embedded secret. Generic CalDAV discovery does not register an OAuth client.

Registering and removing clients requires password and passkey verification within ten minutes. Removing a client revokes every grant issued to it.
