Connection settings

  1. Open the Calendar tab. Choose New Calendar → On the Network.
  2. Enter your username and the server address as Location. Leave This location doesn’t require credentials unchecked, then choose Find Calendars.
  3. Enter your BusyStack application password in Thunderbird’s password prompt.
  4. Choose CalDAV, select the calendars and task lists you need, then choose Subscribe. Use Thunderbird’s task view for tasks.
  1. Open Manage Calendars → Add Calendar. GNOME Calendar manages events.
  2. Paste the GNOME connection address into Connect to an Online Calendar. The address includes your username.
  3. In Credentials, enter your username and application password. Select Connect, then Add Calendar once the address validates.
  4. Use the same application password if GNOME prompts again during synchronization.

Choose CalDAV with password authentication using the configured server address. Enter your username and a BusyStack application password. Discovery can find resources you own or can access by sharing. Select an app that supports the resource types you need.

Refresh in your app and check that the expected resources appear. For a writable resource, create a test item and check that it synchronizes before adding important data.
