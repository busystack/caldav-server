# 0.2.0 development

This branch adds a server-rendered account and administration portal: collection
metadata/lifecycle, per-collection direct/group/effective access, connections,
security organization, contextual setup, bounded account/group/audit screens,
operational diagnostics and confirmed iCalendar portability. It retains the
existing Java/Spring/Thymeleaf/PostgreSQL stack and V1–V14 schema.

Start with the [user guide](../portal.md), [administration guide](../administration.md)
and [portability limits and representation](../portability.md). The optional
Keycloak identity, recent-factor, recovery, OAuth, credential and CalDAV policies
remain unchanged. Proxy import limits need the documented dedicated location.

This document describes development functionality, not release qualification or
readiness. Exact source/artifact, executed browser/client/security/recovery results
and unverified environments must be recorded independently before publication.
Historical 0.1.0 client results do not qualify a different executable.

The corrective pass adds bounded disk-indexed 64 MiB / 10,000-series import,
transaction-aware confirmation retry, private crash cleanup, a shared temporary
storage ledger, metadata-only group rename, editable accessible field errors and
opaque administrative audit targets (V14). It also selects official Temurin
25.0.5+8 security maintenance binaries without modifying third-party software.
Exact executed results and outstanding release gates remain separate evidence.
