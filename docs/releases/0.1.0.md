# BusyStack CalDAV Server v0.1.0

## Overview

BusyStack CalDAV Server is a self-hosted server for calendars and tasks, with
PostgreSQL persistence and account administration. v0.1.0 provides the correctly
versioned release with verified installation and publication infrastructure.
Existing CalDAV functionality and compatibility behavior are preserved.

## Installation

The recommended distribution is `caldav-server-0.1.0-deploy.tar.gz`. Download it,
`SHA256SUMS` and `release-manifest.json` from the
[release assets](https://github.com/busystack/caldav-server/releases/tag/v0.1.0),
verify checksums, extract it and follow its `INSTALL.md`.

The bundle requires Linux AMD64, Docker Engine and Compose v2 (2.24.4 or newer).
It pulls the application by immutable registry digest and includes PostgreSQL.
Supply your own domain, HTTPS termination and private secrets. No source checkout,
Maven or host Java is needed. The alternative `caldav-server-0.1.0.jar` requires
Java 25 and PostgreSQL 18.6 managed by the administrator.

## Compatibility

Qualified real-editor profiles cover Thunderbird 159.0 with system and explicit
America/Vancouver and explicit Europe/Berlin, and GNOME Calendar 50.0 / Evolution
Data Server 3.56.2 with America/Vancouver. See
[compatibility details](../observance-until-compatibility.md), including the
existing local-observance `UNTIL` repair and synchronization Depth behavior.

## Important limitations

The account interface is not a calendar editor. CardDAV, scheduling/invitation
delivery, alarm execution and automatic failover are unsupported. See
[calendar semantics](../calendar-semantics.md) for the supported protocol profile.
