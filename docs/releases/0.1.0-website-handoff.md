# Website handoff: BusyStack CalDAV Server v0.1.0

This handoff describes the repository's v0.1.0 distribution. Website edits and
deployment are a separate task; this release does not modify `busystack.org`.

Use the [GitHub release](https://github.com/busystack/caldav-server/releases/tag/v0.1.0)
and its [release manifest](https://github.com/busystack/caldav-server/releases/download/v0.1.0/release-manifest.json)
for the published source revision, checksums, registry digest and verification
identities. Verify those public assets before updating website installation links.

The primary installation is `caldav-server-0.1.0-deploy.tar.gz`, with Docker Engine
and Compose v2 on Linux AMD64. Its Compose configuration pulls
`ghcr.io/busystack/caldav-server:0.1.0` pinned to the manifest's immutable digest and
includes a private PostgreSQL service. Users supply their domain, HTTPS termination
and private secrets. No source checkout, Maven or host Java is required.
`caldav-server-0.1.0.jar` is the alternative for Java 25 / PostgreSQL 18.6 operators.
The release also supplies `SHA256SUMS`, `sbom.cdx.json` and `notices.tar.gz`.

Describe calendar/task collections, recurrence, synchronization, sharing and
account administration within the [release notes](0.1.0.md) and
[documented limitations](../calendar-semantics.md). The account UI is not a calendar
editor. Do not claim CardDAV, scheduling/invitation delivery, alarm execution,
additional platforms or high availability. Client support is limited to the
recorded Thunderbird and GNOME Calendar configurations.

Link installation, administrator bootstrap, passkeys/MFA, named DAV credentials,
backup and restoration guidance. Preserve the documented compatibility controls,
Apache-2.0 license and third-party notices. No additional package format is offered.
