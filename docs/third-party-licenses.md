# Third-party license inventory and review

The exact runtime module inventory is the generated CycloneDX file, `target/classes/META-INF/sbom/application.cdx.json`, embedded at `META-INF/sbom/application.cdx.json` in the executable JAR. It records each Maven package URL, resolved version and POM-declared license. CI retains this file for the artifact it built. Use [the build instructions](operations.md) to regenerate it; the dependency-management baseline and [version pins](versions.md) are maintained separately.

The 2026-10-27 final source build contains 112 runtime Maven component entries, all with license metadata. The project root component records Apache-2.0, selected by the owner. Third-party component license declarations remain their original upstream metadata. Counts are observations of that generated artifact, not a substitute for regenerating the inventory after dependency changes. POM metadata is evidence to inspect, not a substitute for the license files and notices in the actual distribution.

## Distribution obligations and actual delivery

The owner selected **Apache License 2.0**. The root `LICENSE` is the unmodified official ASF text, SHA-256 `cfc7749b96f63bd31c3c42b5c471bf756814053e847c10f3eb003417bc523d30`; `NOTICE` identifies incorporated source without inventing a legal entity or transferring third-party copyright. `THIRD-PARTY-NOTICES` describes the independent license alternatives and source availability. Source archives include these files; the executable archive packages them in `META-INF` and retains the original nested dependency JARs, their original notices and licensing text. Dependencies with missing JAR license text are covered by the delivered applicable license material, with additional ASM copyright/conditions and Logback license alternatives in `META-INF/licenses`.

The two modified iCal4j source files retain complete Ben Fortuna BSD-3-Clause headers and explicit BusyStack modification notices. Source patches, exact original source hashes and functional rationale remain in the parser/timezone documents. Immutable migrations V3, V4 and V6 retain their original checksum; additional `META-INF/licenses/spring-derived-schemas.txt` identifies the Apache-licensed upstream schema contracts and application changes without modifying an already-applied migration.

The final image exposes project notices under `/opt/busystack/licenses`, retains the executable archive's dependency notices, records OCI project license/source/revision labels, and supplies the runtime inventory as `runtime-dependency-inventory.json`. Eclipse Temurin's original `/opt/java/openjdk/legal` contains GPL-2.0, Classpath Exception, assembly exception and component notices. Its exact [source distribution](https://github.com/adoptium/temurin25-binaries/releases/tag/jdk-25.0.4.1%2B1) remains identified. Ubuntu package copyright/license files remain under `/usr/share/doc`; their inventory and advisories are checked separately from Maven packages. Linking the application does not relicense the JDK or OS. Corresponding source links for the selected unmodified EPL components are delivered in `THIRD-PARTY-NOTICES`.

Run `python3 scripts/verify-distribution.py --image busystack-caldav:ci` after committing and building with the matching `SOURCE_REVISION` build argument. It inspects an actual `git archive` source distribution, executable JAR and final image, records nested original notice hashes and compares host/container JAR bytes. This is reproducible distribution evidence, not a replacement of third-party licenses or an external legal certification. Investigation and qualification dependencies are excluded from production scope; their inventories and image licenses remain separate.
