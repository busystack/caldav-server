Tests listed here must be read with the executed test results; a test's existence is not a pass.

### Deliberate security-profile deviation

RFC 4918 §20's historical Digest requirement is not implemented. The selected design uses HTTPS, revocable DAV credentials, and the approved browser/OAuth security stack. [Spring Security's Digest guidance](https://docs.spring.io/spring-security/reference/servlet/authentication/passwords/digest.html) advises against the password-storage compromises of its Digest support. The application must not weaken password storage or claim literal satisfaction of every historical DAV requirement.

### Specification review status

Primary RFC documents above are the implementation contract. A section-by-section errata/update review and detailed per-requirement protocol traceability remain unfinished. Examples, library feature lists and another server's behavior are not conformance evidence. Before release, each grouped row must be expanded where needed into mandatory/recommended/optional obligations with the actual HTTP tests and relevant verified errata.
